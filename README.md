# Maus-Training

Ein Übungsspiel für Maus-Anfänger: Maus bewegen, links klicken, rechts klicken, doppelklicken und ziehen. Sieben Level, bis zu drei Sterne pro Level, einstellbare Zielgröße und Ton.

Alles steckt in einer Datei: `Maus-Training.html` im Browser öffnen, fertig. Kein Server, keine Installation, kein Internet nötig.
