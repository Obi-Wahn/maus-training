# Maus-Training

Ein Übungsspiel für Maus-Anfänger: Maus bewegen, links klicken, rechts klicken, doppelklicken und ziehen. Elf Level, bis zu drei Sterne pro Level, einstellbare Zielgröße und Ton.

Level 8 bis 11 zeigen nachgebaute Bildschirme (Desktop, Datei-Explorer, Browser) ganz ohne Farbcode: Die Schüler lesen eine Aufgabe wie „Öffne den Ordner »Fotos«“ oder „Speichere das Bild“ und entscheiden selbst, ob ein Doppelklick, ein einfacher Linksklick oder ein Rechtsklick nötig ist. Vor jedem dieser Level erklärt eine Regel-Seite mit Beispielen, wann welcher Klick nötig ist; die ersten Aufgaben sind geführte Übungen mit Tipp, die nicht als Fehler zählen. Jeder richtige Klick zeigt seine echte Folge (Ordner geht auf, Datei verschwindet, Seite lädt …). Bei einem falschen Klick erklärt das Spiel die passende Regel.

Alles steckt in einer Datei: `Maus-Training.html` im Browser öffnen, fertig. Kein Server, keine Installation, kein Internet nötig.
